# 📊 Cosmetics Sales Data Analysis (Excel Project)

An end-to-end Excel project demonstrating **data cleaning, pivot table analysis, and interactive dashboard creation** using cosmetics sales data.

---

## 📁 Project Overview

This project analyzes sales performance across countries and products to extract meaningful business insights.

### 🔍 Key Components:
- 🧹 Data Cleaning
- 📊 Pivot Tables
- 📈 Dashboard
- 📌 Insights

---

## 🧾 Dataset Description

The dataset includes:

- Sales Person  
- Country  
- Product  
- Date  
- Amount ($)  
- Boxes Shipped  
- Product Price  
- Demand Category  

---

## 🧹 Data Cleaning (Working Sheet)

- Cleaned and formatted raw data  
- Ensured correct data types (Date, Currency)  
- Created new columns:
  - Product Price  
  - Demand Category  
- Structured dataset for analysis
